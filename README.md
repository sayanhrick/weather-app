# 🌦️ Weather App

A responsive and user-friendly Weather Application that provides real-time weather information for cities around the world. Users can search for any location and instantly access current weather conditions and important atmospheric details.

The project demonstrates practical frontend development, API integration, asynchronous JavaScript, and responsive UI design.

---

## ✨ Features

- 🌍 **Search by City:** Find weather information for any city.
- 🌡️ **Live Temperature:** Get current temperature and weather conditions.
- 💧 **Humidity:** View current humidity levels.
- 💨 **Wind Speed:** Check real-time wind speed.
- ☁️ **Weather Conditions:** Get information about sunny, cloudy, rainy, and other conditions.
- 📱 **Responsive Design:** Works across desktop, tablet, and mobile devices.
- ⚡ **Real-Time API Integration:** Fetch updated weather data dynamically.
- 🎨 **Clean UI:** Simple and intuitive user experience.

## 🚀 Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/sayanhrick/weather-app.git
```

### 2. Navigate to the Project Directory

```bash
cd weather-app
```

### 3. Configure API Key

If the application requires an API key:

- Obtain an API key from your weather data provider.
- Add the API key to the appropriate configuration in your JavaScript code.
- Avoid committing private API keys to GitHub.

### 4. Run the Application

Open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.
